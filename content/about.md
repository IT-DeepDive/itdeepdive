# About this website
[![](/logos/itdeepdive-logo-dark.png "IT DeepDive logo")](https://itdeepdive.com)\
I've always wanted to have my personal website for many reasons. For example:
- Keep notes of my daily work as a Senior Engineer
- Showcase new products / technologies
- Improve my communication skills
- Share my knowledge as many others do, with intent of helping each other
- Learn how to Blog

From a technology stand point, this is a static website leveraging [HUGO](https://gohugo.io/) static site generator.\
The theme in use is [Clarity](https://themes.gohugo.io/hugo-clarity/) with some minor customizations.\
[IT DeepDive](https://itdeepdive.com) is hosted on [GitLab](https://gohugo.io/hosting-and-deployment/hosting-on-gitlab/) where every time I push an update via git, a CI Pipeline takes care of building the static content and publishing the website.\
